12 Automations — The Company Runs on Autopilot

01
Vacancy > 10% → Urgent Leasing Task
Property crosses threshold → ClickUp urgent task + regional manager Outlook alert. 48hr deadline.
02
NSPIRE Date → 60/30/14/2-Day Prep Sequence
Inspection logged in PM 2.0 → Claude generates prep checklist → 4 tasks auto-created in Compliance space.
03
Call Score < 70 → Coaching Task
Phone Portal recording → Claude scores 5 Golden Questions → below threshold → coaching task for regional manager.
04
Monday 7AM → Portfolio KPI Brief
Every Monday → Claude reads Vacancy App → 5-region brief → Leadership ClickUp task + email to Marc/Nicole/Brandon/Robert.
05
COI Expiring 30 Days → Renewal Alert
Compliance Space trigger → Claude drafts renewal request → Ethan + Mercy notified. No expired COI vendor gets paid.
06
Sensor Alert → Emergency Maintenance Task
IoT alert from PM 2.0 → ClickUp emergency task instantly → Ethan + regional manager within 2 minutes.
07
AppWork Overdue → Weekly Escalation
Weekly AppWork export → Claude flags overdue orders → Ethan gets unified summary with all Yardi-property backlog.
08
1st of Month → Accounting Close Checklist
Auto-creates Genesis reports, Webster reconciliation (due 5th), BofA reconciliation, PSI Safe filings — all assigned.
09
1st of Month → Training Leaderboard Email
Claude pulls quiz scores + call scores + conversions → ranks all managers → leaderboard email to all 5 regional managers.
10
Purchase > Threshold → Approval Task
PM 2.0 Purchasing request → Claude checks vendor COI → if valid, creates ClickUp approval task for Ethan/Nicole.
11
Every Other Friday → Payroll Checklist
Bi-weekly recurring → Helen Guei (LA payroll) + NY Menowitz team. New hire auto-adds payroll setup subtask.
12
Missed Prospect Call → Callback Task + Script
Phone Portal missed call → ClickUp task in property list → Claude generates 5 Golden Questions callback script. Due: 2hrs.
