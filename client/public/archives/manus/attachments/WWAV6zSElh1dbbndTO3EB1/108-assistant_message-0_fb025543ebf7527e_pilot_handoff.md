# PropertyMax General Pilot Handoff

The ClickUp staging environment has been simplified to a general collaboration pilot. It now demonstrates two core capabilities: **communication through existing Chat channels** and **shared to-do/task tracking using non-sensitive PropertyMax property references**.

| Pilot component | Final setup |
|---|---|
| Staging Space | `STAGING — PropertyMax R3 Pilot` |
| Task location | `00 — Pilot Control Center` → [PropertyMax Pilot Tasks](https://app.clickup.com/90141135992/v/l/li/901418106094) |
| Communication channels | Existing public `Operations` and `Managers` channels |
| Property reference data | Property codes/names and manager/contact-routing references only |
| Sample work | Four verified tasks, all in `To do` status and intentionally unassigned |

The sample tasks cover the Bayou Pointe/North Pointe manager assignment, the Marrero 3/Ruby Diamond mapping, the Gates on Manhattan reception contact, and a Region 3 communication-to-task handoff. Each task instructs testers to keep coordination brief in Chat, link back to the task, and avoid resident names, unit ledgers, financial details, and other sensitive source information.

The existing 11-property directory remains available as a PropertyMax reference, but the earlier detailed per-property workflow expansion has stopped. Custom status propagation, specialized property workflows, automations, Forms, dashboard refinement, and property-team invitations are deferred unless requested later.

> **Recommended pilot test:** Use the `Operations` channel for a short discussion about one sample task, link the task, identify an owner in ClickUp, move it through `To do` → `In progress` → `Complete`, and record the final outcome in the task rather than the channel.

The List and all four tasks were independently verified after creation. The `Operations` and `Managers` channels were also verified as available public Workspace channels. No Chat messages were posted and no property-team users were invited during setup.
