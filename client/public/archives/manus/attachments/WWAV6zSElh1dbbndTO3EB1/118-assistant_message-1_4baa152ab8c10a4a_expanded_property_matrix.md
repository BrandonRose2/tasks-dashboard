## Enrichment rules

Every pilot task should identify the property code and name, source-system context, responsible role or unresolved routing issue, concrete action steps, acceptance criteria, the appropriate existing Chat channel, and the excluded-data boundary. Tasks remain unassigned until a person is a verified ClickUp member.

The source database supports additional fields such as office phone, extension, mobile, street address, city, state, ZIP, and time zone. These values should be added only when directly verified for the relevant row. No blank value should be inferred or replaced with an estimate.
