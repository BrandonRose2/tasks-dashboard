# How to Add Custom Fields in ClickUp — Manager's Contact List

Follow these steps in your ClickUp workspace to add the same columns that exist in your Notion "By Region" view.

---

## Step 1 — Open Your List in Table View

1. Go to your **Manager's Contact List** Space:
   👉 https://app.clickup.com/90141135992/v/l/li/901415573747
2. Make sure you are in **List view** (click the view tabs at the top if needed).
3. Switch to **Table view** by clicking the **"+ Add View"** button at the top left, then selecting **Table** — this gives you the spreadsheet-style column layout like Notion.

---

## Step 2 — Add a New Custom Field (Column)

1. In Table view, scroll all the way to the **right** of the column headers.
2. Click the **"+" (plus) icon** at the end of the column headers row — this opens the **Add Field** panel.
3. A menu will appear asking you to choose a field type.

---

## Step 3 — Create Each Field

Add the following fields **one at a time**, using the field types listed below. After each one, click **"+ Add Field"** again to add the next.

| Field Name | Field Type | Notes |
|---|---|---|
| **Property** | Text | The property/location name |
| **Manager** | Text | Manager's full name |
| **Email Address** | Email | Manager's email |
| **Office** | Phone | Office phone number |
| **Ext** | Text | Phone extension |
| **Mobile** | Phone | Mobile phone number |
| **Street Address** | Text | Full street address |
| **City** | Text | City name |
| **State** | Text | State abbreviation (e.g. FL, TX) |
| **Zip** | Text | ZIP code |
| **Region** | Dropdown | Options: Region 1, Region 2, Region 3, Region 4, Region 5 |
| **Time Zone** | Dropdown | Options: EST, CST, PST |
| **Trained** | Dropdown | Options: Yes, No, Scheduled, Missed |
| **Payroll** | Text | Payroll designation |
| **Status** | Status | Uses ClickUp's built-in Status field (already exists) |

> **Tip:** For **Dropdown** fields, after selecting "Dropdown" as the type, click **"+ Add option"** to enter each option value.

---

## Step 4 — For Each Field, Set the Name and Save

1. In the **Add Field** panel, type the **field name** exactly as shown in the table above.
2. Select the **field type** from the list.
3. Click **"Create"** or **"Save"**.
4. The new column will appear in your Table view.

---

## Step 5 — Group by Region

Once the **Region** dropdown field is created:

1. Click the **"Group by"** button in the top toolbar (looks like stacked lines).
2. Select **Region** from the dropdown.
3. Your tasks will now be grouped into **Region 1 through Region 5** — exactly like the Notion view.

---

## Step 6 — Let Me Fill in the Field Values

Once you've created the custom fields, **come back here and let me know** — I'll automatically populate all 60 records with the correct values for every field (Manager, Email, Office, Mobile, Address, City, State, Zip, Region, Time Zone, etc.) so you don't have to do it manually.

---

## Quick Reference — Field Types in ClickUp

| ClickUp Field Type | Use For |
|---|---|
| **Text** | Names, addresses, extensions, zip codes |
| **Email** | Email addresses (clickable link) |
| **Phone** | Phone numbers (clickable to call) |
| **Dropdown** | Region, Time Zone, Trained status |
| **Status** | Built-in task status (already on every task) |
