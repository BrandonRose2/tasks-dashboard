# PropertyMax.ai Platform Overview

PropertyMax.ai is a comprehensive property management platform designed to streamline operations, track key performance indicators, and manage daily tasks for property managers and staff. Below is a detailed description of five key sections within the application: Dashboard, My Profile, Reports, Appointments, and Rental Comps.

## 1. Dashboard

The Dashboard serves as the central hub for property managers, providing a high-level overview of critical metrics and daily operations. It is designed to give users immediate visibility into the health of their properties. The top navigation bar displays the system health status and the last sync time, while providing quick access to various modules such as Vacancy, AI Bot, AppWork, Inspections, Paychex, and Yardi.

A prominent Collections Overview widget displays financial metrics for the selected property for the current month. It shows the total amount billed, the amount collected, and the outstanding balance, allowing managers to quickly assess revenue performance. The Dashboard also includes sections dedicated to tracking delinquent accounts and pending tasks, ensuring nothing falls through the cracks. Users can view their personal tasks, guest card tasks, maintenance tasks, and rent-related tasks.

Communication is heavily integrated into the Dashboard. A comprehensive communication log tracks incoming and outgoing calls, complete with audio playback, caller details, and AI-generated summaries. It also includes a robust SMS interface showing recent text conversations with prospects and tenants, categorized by marketing and non-marketing messages. Finally, an Inspections widget provides quick access to view upcoming and pending inspections, filterable by status and unit, showing details like the tenant name, scheduled date, and assigned inspector.

## 2. My Profile

The My Profile section is a personalized workspace for individual staff members, combining human resources information with a comprehensive daily schedule. It displays the user's name, contact information, hire date, and upcoming anniversary date.

A significant portion of the profile is dedicated to time-off management. It provides a detailed summary of accrued, used, and available sick time and vacation time. Users can initiate new time-off requests directly from this interface.

The core of the My Profile section is an interactive, color-coded calendar view that consolidates the user's schedule. The calendar integrates multiple data streams to provide a complete picture of the day's responsibilities.

| Calendar Event Type | Description |
| :--- | :--- |
| **Inspections** | Scheduled property and unit inspections, such as move-in inspections or final charges/pictures. |
| **Maintenance** | Assigned work orders categorized by issue type (e.g., HVAC, Plumbing, Appliance) with detailed descriptions of the problem. |
| **Appointments** | Scheduled meetings, tours, or lease signings with prospects or tenants. |
| **Time Off** | Approved sick days, vacation days, or company travel. |

## 3. Reports

The Reports section provides analytical tools to help property managers make data-driven decisions. Currently, the primary focus is on marketing analytics through the Marketing Report tool.

This tool allows users to analyze lead generation sources for specific properties over a selected date range. The report generates a horizontal bar chart displaying the count of referrals from various channels. Common sources tracked include Friends and Family, Apartments.com, Google, Driveby traffic, Facebook, affordablehousing.com, and various Housing Authorities. This data is crucial for evaluating the return on investment of different marketing campaigns and adjusting strategies accordingly.

## 4. Appointments

The Appointments module is a dedicated system for scheduling and managing interactions with prospects, tenants, and vendors. It features a centralized list displaying all upcoming appointments, complete with a badge indicating the total count of scheduled events.

When creating a new appointment, users are presented with a detailed scheduling interface. This form allows staff to specify the building, the specific unit involved, and the date and time of the meeting. The system categorizes appointments into types such as Tour, Signing, Maintenance, Vendor, Inquiry, or Rent. Users can also input caller and recipient phone numbers, link the appointment to an existing tenant, or add the individual to a tenant guest card for prospect tracking. A summary text area is provided for detailed notes regarding the appointment's purpose.

## 5. Rental Comps

The Rental Comps (Comparables) section is a vital tool for market analysis, allowing property managers to benchmark their rental rates against competing properties in the area. The system tracks specific competing properties to provide a comprehensive view of the local market landscape.

The data is segmented into "Market Rate Comps" for properties with no income restrictions, and "Affordable Comps" for properties participating in programs like LIHTC, Section 8, or HUD. Users can generate and view a published sheet for external sharing or offline analysis.

| Comparable Metric | Description |
| :--- | :--- |
| **Proximity** | The distance of the competing property from the subject property (e.g., 3.9 miles). |
| **Unit Types** | Detailed rent breakdowns for 1-bedroom, 2-bedroom, 3-bedroom, and 4-bedroom units. |
| **Pricing Tiers** | For each unit type, the table displays the Low rent, High rent, Fair Market Rent (FMR), and the Market Average. |
