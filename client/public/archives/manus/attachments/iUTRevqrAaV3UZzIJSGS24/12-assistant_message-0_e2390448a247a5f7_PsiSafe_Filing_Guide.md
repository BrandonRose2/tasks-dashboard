# PsiSafe Mortgage Statement Filing Guide

This guide provides a structured mapping for filing the 21 mortgage statement PDFs into PsiSafe. Based on the provided screenshots, the filing structure follows the **Repository > Cabinet > Document List (Vendor) > Document Title** hierarchy.

## Filing Parameters

*   **Repository:** Accounting
*   **Document Title Format:** `MSD 04-24-2026 - [Property Name]` (or simply `MSD 04-24-2026` if the property name is not appended, though appending it is recommended based on the example `MSD 04-24-2026 - Cumberland`).
*   **Tab:** Bills

## Batch Filing Strategy

While PsiSafe does not always support "drag-and-drop" bulk filing into multiple different folders simultaneously without an import template, you can streamline the manual process using the **Batch Capture** or **Explorer** features visible in your PsiSafe dashboard.

1.  **Use the Explorer Pane:** You can navigate to the folder where your PDFs are stored (e.g., `Desktop > Mortgage Statements`) directly within the PsiSafe Explorer pane on the left.
2.  **Process One by One:** Select a document, choose the correct Cabinet (Property), select the Vendor (e.g., Webster Bank), and apply the title `MSD 04-24-2026`.
3.  **Copy-Paste Title:** To save time, copy the base title `MSD 04-24-2026 - ` to your clipboard and paste it for each file, typing only the property name at the end.
