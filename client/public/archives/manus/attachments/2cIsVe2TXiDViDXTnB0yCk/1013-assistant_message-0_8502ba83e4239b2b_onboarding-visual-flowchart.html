5
Payroll & Accounting Setup
Owner: Accounting Team
💰
Create New Hire Profile in Paychex
Accounting uses the W-4, IT-2104, and Direct Deposit Authorization forms to create the payroll profile in Paychex. Assigns pay schedule, department code, pay rate, and tax withholding settings.
Accounting Paychex
🏦
Configure Direct Deposit
Accounting enters the new hire's bank account information into Paychex to activate direct deposit. First paycheck will be issued via direct deposit on the next scheduled pay date.
Accounting Paychex
📧
Paychex Welcome Email Sent to New Hire
Paychex automatically sends the new hire a welcome email with a link to set up their employee self-service account for viewing pay stubs, requesting PTO, and managing benefits.
Automated by Paychex To: New Hire
🏥
Benefits Enrollment Window Opened
Accounting opens the benefits enrollment window in Paychex. New hire has 30 days to select health insurance, dental, vision, and other available benefits. Accounting confirms enrollment before closing the window.
Accounting

Completion Email Sent to New Hire
System sends an official welcome email to the new hire confirming they are fully onboarded. A summary notification is also sent to Brandon and Marc.
Automated To: New Hire · CC: Brandon · Marc
⏱️
Automated 3-Hour Onboarding Alert
If the onboarding process has been in progress for more than 3 hours without reaching completion, the system automatically sends an alert email to Brandon. The alert includes the new hire's name, email address, how long they have been in the process, and a list of which steps are still incomplete — allowing HR to follow up proactively and keep the process on track.

Automated · Runs every 30 minutes To: Brandon
10
Server File Archiving
Owner: System — automated upon completion
🗄️
All Files Archived to Service Server
Upon completion of the onboarding process, all submitted forms, signed documents, training acknowledgments, and the credentials PDF are archived to the ApartmentCorp service server.
Automated Service Server
📂
File Path
Source → Server → Core Data → New Hire Onboarding Folders
Each new hire has their own dedicated folder organized by name and hire date. Records are retained indefinitely for compliance, auditing, and future reference.
