# ApartmentCorp Portfolio Website Audit Report

This report provides a comprehensive audit of the properties listed on the [ApartmentCorp Portfolio](https://apartmentcorp.com/portfolio) page. The audit focuses on three key areas: identifying properties that lack navigation links to external listing sites, verifying the visibility of pricing information on the available listing sites, and evaluating the authenticity of the property images used on the portfolio page.

## 2. Pricing Visibility on Listing Sites

For the 26 properties that do have navigation links, a spot-check of the external listing sites (such as Apartments.com, ApartmentFinder, and AffordableHousing.com) revealed that **pricing is generally not visible** for the specific units.

In almost all cases checked, the listing pages either state "Call for Rent," "Contact for Pricing," or do not list specific unit prices. This is common for Low-Income Housing Tax Credit (LIHTC) and affordable housing properties, where rent is often based on income limits rather than a fixed market rate.

It is also worth noting that the link for "Riverchase" in Augusta, GA, incorrectly navigates to a property named Riverchase in Dover, DE.

## 3. Image Authenticity and AI Generation

An evaluation of the property images on the portfolio page indicates that several images appear to be AI-generated, stock photos, or architectural renderings rather than authentic photographs of the actual properties. This could be perceived as false advertising or misrepresentation.

### Suspected Inauthentic Images

| Property Name | Location | Observation |
|---|---|---|
| Riverchase | Augusta, GA | The image shows a highly polished architectural rendering of townhomes. It lacks real-world imperfections and appears to be a 3D render or AI-generated image rather than an actual photograph. |
| Silver Springs | Hickory, NC | The image displays a large, elegant white colonial-style home with a wrap-around porch. This appears to be a stock photo of a luxury single-family home, which does not align with the description of a 100-unit LIHTC affordable housing complex. |
| Lexington Arms Apartments | Waxahachie, TX | The image shows a modern, ultra-luxury, multi-level home with a pool, which strongly contrasts with the description of a 61-unit single-family LIHTC property. This is highly likely a stock photo or AI generation. |
| La Promesa | Odessa, TX | The image features a highly stylized, modern architectural design that looks like a 3D rendering rather than a real-world photograph of a 136-unit HUD/LIHTC apartment community. |

### Confirmed Authentic Images

Several properties do feature authentic photos, often showing actual signage or realistic building conditions. For example, Thomasville Church Homes, Boca Ciega, and Macedonia all have visible property signage in their photos, confirming their authenticity. Opa Locka also features a realistic building photo that aligns with its description.

## Conclusion

To improve the user experience and transparency of the ApartmentCorp portfolio page, it is recommended to add external listing links for the 16 properties currently lacking them, if available. Furthermore, clarifying on the portfolio page that pricing is income-restricted or requires contacting the property directly would set proper expectations before users click through to external sites. Finally, replacing the suspected stock photos and AI-generated renderings with authentic photographs of the actual properties would help avoid misleading potential residents or investors.
