## Proposed scope

Each proposal retains the original federal return through the listed final embedded federal K-1 packet, removes all subsequent material, and redacts only the listed high-confidence investor/partner SSN, TIN, or investor tax-ID fields. Partnership/entity EINs, financial information, names, addresses, and other content remain visible.
