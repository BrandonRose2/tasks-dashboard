1. Recover the pipeline. Extract the recurring-rentcomps directory from the Reports project file ApartmentCorp_Monthly_RentComps_Recovery.zip, install its requirements and run its tests, then follow MONTHLY_RUN_PLAYBOOK.md in full. Never assume a previous sandbox's files persist. If the files cannot be recovered, stop and record the exact failure in Manus; never email an older workbook as a refreshed report.

2. Establish the baseline. Use the latest approved formatted workbook from project files or the approved SharePoint source. The bundled baselines/RentComps_UPDATED_Aug2026.xlsx may supply existing comparable identities and formatting only, with its age disclosed, and its market rents must still be freshly researched. Preserve the input workbook and verify its SHA-256.

3. Extract and research. Run pipeline.py extract to discover the actual subject tabs, comparable rows, requested bedroom types and checksum. Research every existing market-rate comparable row for every requested bedroom type through parallel workflow agents against current public sources (Apartments.com primary, official community floor-plan/availability pages, Zillow or Apartment Finder as fallback). Recover only incomplete properties. Baseline prices are never evidence of current rents; unresolved cells become Phone Verify, never old numbers.

4. Review conservatively. Validate with integrate_results.py and precheck.py. Exclude fee-inclusive totals, arithmetic derivations, concession-adjusted or per-bed pricing, and any comparable whose eligibility or identity stays unresolved, recording each decision through apply_review.py or a documented eligibility adjudication that preserves the original finding and reason.

5. Build and verify. Run pipeline.py build from genuine current observations only, never in test mode, and fail closed on stale evidence, missing coverage, checksum mismatch, prohibited pricing evidence or wholly Phone Verify research. Then run verify_report.py to confirm workbook readback and market-average tie-outs, and generate the review checklist with render_review_checklist.py plus manus-md-to-pdf covering all properties. Verify the actual workbook and the actual PDF.
